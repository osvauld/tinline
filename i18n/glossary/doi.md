# Dogri (doi), डोगरी

Read `india.md` first. Confidence: **low**. Machine drafts for Dogri usually come
out as Hindi or Punjabi with a few Dogri forms. A Dogri speaker must rewrite them.

## Script and layout
- **Devanagari**, the official script (Takri is historic; Perso-Arabic was also used).
  Left to right. Sentence end `।`.

## Register
Polite **तुस** (tus) **verify**, not तूं (familiar). Verb endings mark gender, like
Punjabi and Hindi.

## Buttons ("I/my")
"मेरा/मेरी" + polite imperative ("मेरा खाता बनाओ" **verify** Dogri imperative form).
First person is gendered: only use gender-free constructions (transitive past with
the agent marker, which agrees with the object, e.g. "मैं सांभी लेई" **verify**).

## Plurals (CLDR)
`one` (0 and 1), `other`. Keep `{count}` in `one` since 0 uses it. If an OS has no
Dogri rule it uses `other` for all counts; make `other` read acceptably for 1.

## Names and brand
"Tinline", "Osvauld", "DID" in Latin; postpositions as separate words.
