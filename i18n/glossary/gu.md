# Gujarati (gu), ગુજરાતી

Read `india.md` first. Confidence: **medium**. Machine drafts are understandable but
stiff and sometimes carry Hindi word order or words.

## Script and layout
- Gujarati script, left to right. System fonts. No headline bar (unlike Devanagari).
- Sentence end `.` (Gujarati uses the Latin full stop in modern writing).

## Register
**તમે** (polite plural). Normal respectful address in Gujarati apps and conversation.
આપ is very formal/ceremonial; તું is intimate.

## Buttons ("I/my")
"મારું/મારા/મારી" + polite imperative: "Create my account" → "મારું એકાઉન્ટ બનાવો",
"Copy my words" → "મારા શબ્દો કૉપિ કરો". Gujarati past tense agrees in gender: use
transitive past with "મેં", which agrees with the object: "I’ve saved them" → "મેં સાચવી
લીધા" **verify**. "હું તૈયાર છું" is fine (the adjective doesn't change); avoid
"હું ગયો/ગઈ" type forms. "Not now" → "હમણાં નહીં".

## Plurals (CLDR)
`one` (0 and 1), `other`. 0 is `one`: keep `{count}`.

## Names and brand
"Tinline", "Osvauld", "DID" in Latin; postpositions separate ("Tinline માં").
