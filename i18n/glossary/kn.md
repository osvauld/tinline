# Kannada (kn), ಕನ್ನಡ

Read `india.md` first. Confidence: **medium**. Machine drafts are understandable but
stiff (Sanskrit-heavy) and sometimes use spoken Bengaluru forms inconsistently.

## Script and layout
- Kannada script, left to right. System fonts; tall stacked conjuncts, check clipping.
- Sentence end `.`.

## Register
**ನೀವು** (polite plural), modern standard written Kannada. ನೀನು is familiar.
Polite imperatives end in -ಇ ("ಉಳಿಸಿ"), which is how Android Kannada buttons read.

## Buttons ("I/my")
"ನನ್ನ" + polite imperative: "Create my account" → "ನನ್ನ ಖಾತೆ ರಚಿಸಿ", "Copy my words"
→ "ನನ್ನ ಪದಗಳನ್ನು ನಕಲಿಸಿ". First person is gender-free: "I’ve saved them" → "ಉಳಿಸಿದ್ದೇನೆ".
"I agree" → "ಒಪ್ಪುತ್ತೇನೆ". "Not now" → "ಈಗ ಬೇಡ".

## Plurals (CLDR)
`one` (0 and 1), `other`. **0 is `one`**: keep `{count}`. Plural -ಗಳು: "{count} ಹೊಸ
ಸಂದೇಶ" / "{count} ಹೊಸ ಸಂದೇಶಗಳು".

## Names and brand
"Tinline", "Osvauld", "DID" in Latin. Case suffixes on Latin words with a hyphen
("Tinline-ನಲ್ಲಿ") **verify**, or rephrase. Contacts: honorific -ಆರೆ is gender-free
("{name} ಕರೆ ಮಾಡುತ್ತಿದ್ದಾರೆ").
