# Bodo (brx), बड़ो

Read `india.md` first. Confidence: **low**. Machine translation for Bodo is poor:
expect Hindi or Assamese sentences with a few Bodo words, wrong verb suffixes and
invented terms. Treat every machine draft as a placeholder until a Bodo speaker
rewrites it.

## Script and layout
- **Devanagari**, the official script for Bodo since 1975 (Latin and Assamese
  script were used earlier and are still seen). Left to right. System Devanagari fonts.
- Sentence end `।`.

## Register
Polite 2nd person **नोंथां** (nwngthang) **verify**, rather than the plain नों (nwng).
I am not certain of the conventional honorific level in Bodo UI text; a native
speaker should choose. Bodo verbs do not mark gender, as far as I know **verify**.

## Buttons ("I/my")
"आंनि" (my) + verb **verify**: "Create my account" → "आंनि एकाउन्ट सोरजि" **verify**.
If the first-person framing is unnatural in Bodo, use the plain imperative with "my"
and keep it short.

## Plurals (CLDR)
`one` (exactly 1), `other`. CLDR lists Bodo; whether every OS ships the rule is
uncertain, so make `other` acceptable for 1 too. Bodo plural marker -फोर **verify**;
with a numeral it is usually not needed.

## Names and brand
"Tinline", "Osvauld", "DID" in Latin; postpositions as separate words.
