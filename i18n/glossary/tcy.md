# Tulu (tcy), ತುಳು

Read `india.md` first. Confidence: **low**. Tulu is not a scheduled language and has
very little machine-translation support. Drafts will mostly be Kannada with a few
Tulu words. A Tulu speaker must write every string.

## Script and layout
- **Kannada script**, left to right. This is how Tulu is written today (books,
  newspapers, Tulu Wikipedia). The traditional Tulu–Tigalari script entered Unicode in
  2024 but has almost no font or keyboard support and few readers.
- Kannada system fonts work. Sentence end `.`.
- Tulu is not a system language on most phones: users pick it inside Tinline. Check
  that Android/iOS accept the `tcy` resources and that the language picker shows ತುಳು.

## Register
Polite **ಈರ್** (īr), not ಈ (ī, familiar) **verify**. Tulu verbs carry person and,
in the 3rd person, gender; 1st person is gender-free **verify**.

## Buttons ("I/my")
"ಎನ್ನ" (my) + polite imperative **verify**: "Create my account" → "ಎನ್ನ ಖಾತೆ ಉಂಡು ಮಲ್ಪುಲೆ"
**verify**. Polite imperatives end in -ಲೆ.

## Plurals (CLDR)
No CLDR plural rule that I know of: the OS uses `other` for every count. Write
`other` so it reads for 1 too (a label form "ಪೊಸ ಸಂದೇಶ: {count}" is safest **verify**).

## Names and brand
"Tinline", "Osvauld", "DID" in Latin; case suffixes with a hyphen or rephrase.
