# Marathi (mr), मराठी

Read `india.md` first. Confidence: **medium**. Machine drafts are fair but stiff
(heavy Sanskrit words) and use gendered first-person verbs on buttons.

## Script and layout
- Devanagari (Balbodh style), left to right. Marathi uses ळ and the eyelash ऱ्य;
  check the desktop font renders them.
- Sentence end `.` (modern Marathi uses the Latin full stop, not `।`).
- Digits: the OS may show Devanagari digits (०१२) for Marathi. Never type digits.

## Register
**तुम्ही** (polite plural). Normal in Marathi apps. आपण is very formal and is also
"we (inclusive)", which would be ambiguous; तू is intimate.

## Buttons ("I/my")
Marathi first-person present is gendered (मी करतो/करते). Buttons use polite imperative
+ "माझे/माझा/माझी": "Create my account" → "माझे खाते तयार करा", "Copy my words" →
"माझे शब्द कॉपी करा". Confirmation: transitive past agrees with the object, so "मी ते
जतन केले" (I saved them) is gender-free **verify**. "I agree" → "मला मान्य आहे" (gender-free,
natural). "Not now" → "आत्ता नको".

## Plurals (CLDR)
`one` (exactly 1), `other`. Watch noun plural forms (संदेश/संदेश; सूचना/सूचना).

## Names and brand
"Tinline", "Osvauld", "DID" in Latin; case suffixes Marathi fuses (-ला, -मध्ये) go
after a hyphen or space: "Tinline मध्ये" **verify** house style.
