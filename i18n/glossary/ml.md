# Malayalam (ml), മലയാളം

Read `india.md` first. Confidence: **medium**. Machine drafts are understandable but
tend to be formal/Sanskritised and overuse pronouns.

## Script and layout
- Malayalam script, left to right. System fonts. Words are long (agglutinative):
  check buttons.
- **Chillu letters**: use the atomic chillu code points (ൺ ൻ ർ ൽ ൾ, U+0D7A–U+0D7F),
  not the old consonant + virama + ZWJ sequences. Mixed encodings break search and
  sometimes rendering.
- Sentence end `.`.

## Register
Malayalam verbs don't inflect for person or gender, and the language drops pronouns
freely. **Avoid "you" altogether where possible**: "Save a copy somewhere safe" →
"ഒരു പകർപ്പ് സുരക്ഷിതമായി സൂക്ഷിക്കുക". When a pronoun is needed, use **നിങ്ങൾ**
(standard in apps). താങ്കൾ is very formal; നീ is intimate. Use the -ഉക infinitive-
imperative or the polite -ൂ / -ആം forms consistently (see Buttons).

## Buttons ("I/my")
"എന്റെ" + verb: "Create my account" → "എന്റെ അക്കൗണ്ട് സൃഷ്ടിക്കുക", "Copy my words"
→ "എന്റെ വാക്കുകൾ പകർത്തുക". The -ഉക form is the normal Malayalam button form.
First person is gender-free: "I’ve saved them" → "ഞാൻ സേവ് ചെയ്തു" / "സൂക്ഷിച്ചു".
"I agree" → "ഞാൻ സമ്മതിക്കുന്നു". "Not now" → "ഇപ്പോൾ വേണ്ട".

## Plurals (CLDR)
`one` (exactly 1), `other`. Plural -കൾ: "{count} പുതിയ സന്ദേശം" / "{count} പുതിയ
സന്ദേശങ്ങൾ".

## Names and brand
"Tinline", "Osvauld", "DID" in Latin. Case suffixes with a hyphen ("Tinline-ൽ")
**verify**, or rephrase so the name is the subject.
