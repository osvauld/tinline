# Konkani (kok), कोंकणी

Read `india.md` first. Confidence: **low**. Machine drafts for Konkani often come out
as Marathi (आहे instead of आसा, मध्ये instead of -ांत). A Konkani speaker must check.

## Script and layout
- **Devanagari**, the official script (Goa Official Language Act). Konkani is also
  written in Roman (Romi, widely read by Goan Catholics), Kannada (coastal Karnataka)
  and Malayalam scripts. `kok` here is Devanagari only. **Product question**: whether
  Romi Konkani (`kok-Latn`) matters for the audience.
- Left to right. Sentence end `.` in modern usage **verify** (`।` also seen).

## Register
Polite **तुमी** (tumi), not तूं. Verbs mark gender in several tenses.
Use standard (Antruz) Goan Konkani as taught in schools **verify**.

## Buttons ("I/my")
"म्हजें/म्हजो/म्हजी" (my, agrees with the noun) + polite imperative: "Create my
account" → "म्हजें खातें तयार करात" **verify**. First person verbs are gendered; use
"हांवें … केल्यात" (agent + object agreement) style **verify**.

## Plurals (CLDR)
`one`, `other` **verify** (Konkani plural rules in CLDR are uncertain to me). Make
`other` acceptable for 1 in case the OS has no rule.
