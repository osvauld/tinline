# Maithili (mai), मैथिली

Read `india.md` first. Confidence: **low**. Machine drafts for Maithili usually come
out as Hindi with a few Maithili endings. A Maithili speaker must rewrite them.

## Script and layout
- **Devanagari** (Tirhuta/Mithilakshar is the historic script; Devanagari is standard
  today). Left to right. Sentence end `।`.

## Register
Polite **अहाँ** (ahā̃) **verify**; अपने is a higher honorific, तों familiar. Maithili
verbs agree with the honorific level of both subject and object, which machine drafts
get wrong. Pick अहाँ-level forms and keep them.

## Buttons ("I/my")
"हमर" (my) + polite imperative: "Create my account" → "हमर खाता बनाउ" **verify**.
Maithili verbs mark gender less than Hindi **verify**; still prefer object-agreeing
past ("हम सहेजि लेलहुँ" **verify**).

## Plurals (CLDR)
I am not aware of a CLDR plural rule for Maithili **verify**. If the OS has none it
uses `other` for every count: write `other` so it reads for 1 too (Maithili rarely
marks plural with numerals, so this is usually easy).

## Names and brand
"Tinline", "Osvauld", "DID" in Latin; postpositions as separate words.
