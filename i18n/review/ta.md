## Verdict

**Ship as a draft.** The Tamil is plain modern written Tamil in the நீங்கள் register throughout: polite -உங்கள் imperatives in text (சேமியுங்கள், முயலுங்கள்), short plain imperatives on buttons (சேமி, ரத்துசெய், என் கணக்கை உருவாக்கு), gender-free first person on buttons (சேமித்துவிட்டேன், எழுதி வைத்துவிட்டேன், ஒப்புக்கொள்கிறேன்), and the gender-free honorific -ஆர் for contacts (`{name} அழைக்கிறார்`). No spoken forms (பண்ணுங்க, இருக்கு), no literary or government words, no தயவுசெய்து, தோல்வி or தவறான; the one பிழை is “typo” (எழுத்துப் பிழை), which is right. No exclamation marks. Glossary terms are used the same way in all three platforms: மூல ரகசியம் (once, in the debug-log note), மீட்பு வார்த்தைகள் for both “recovery words” and “recovery phrase” (one term, good), கடவுச்சொற்றொடர், அழைப்பு, செய்தி, தொடர்பு, சாதனம், சாதனத்தை இணை / இணைப்பை நீக்கு, தடு / தடையை நீக்கு, குழு, ஹோஸ்ட், நிர்வாகி, உறுப்பினர், ஒலியடக்கு, தவறிய அழைப்பு, ரிலே, காப்புப்பிரதி, அமைப்புகள். Placeholders, `**bold**` pairs and `[label](terms|privacy)` targets match English in every entry (script-checked before and after). Plurals: `one`/`other` everywhere; the two `one` forms without `{count}` (“One more flag…”) are correct because Tamil `one` is exactly 1.

Things done well: `{name} அவர்களின்` / `{name} அவர்களுக்கு` for names, `{group} குழுவை`, `{device} சாதனத்தை` (an apposition noun carries the case, so nothing is fused to a slot); case on numbers with a hyphen (`{total}-இல் {n}-ஆவது`), which is normal written Tamil for digits; a comma after `{by}` in two-name system lines (`{by}, {sub} அவர்களை நிர்வாகி ஆக்கினார்`) so the two names don't run together; the named / unnamed / you variants all agree (நீங்கள் … நீக்கினீர்கள், யாரோ ஒருவர் … நீக்கினார்); “Your account is yours” lines are calm (உங்கள் கணக்கு உங்களுடையது); “Blocking is not silent” = தடுப்பது ரகசியமாக நடக்காது; the CLDR month and weekday names are exact.

Checks run after the edits: `python3 scripts/i18n_tm.py apply ta` (1618 / 1519 / 1263 entries) and `python3 scripts/i18n_gen.py --check` (passes, exit 0). The edit script asserted for every fix that placeholders and `**` pairs are identical before and after, and that the TOML parses.

| Native vs loan: அழைப்பு / செய்தி vs கால் / மெசேஜ் | **Native, as translated.** Google Phone, Google Messages and WhatsApp in Tamil all show அழைப்பு (தவறிய அழைப்பு, உள்வரும் அழைப்பு, குரல் அழைப்பு, வீடியோ அழைப்பு) and செய்தி / செய்திகள். கால் and மெசேஜ் are what people say aloud, but in app text they look like chat slang. Keep ta.md's rule; loans stay where Android uses them (ஆன்லைன், ஹோஸ்ட், ரிலே, ஸ்கேன், ஆப், ஃபோன், பிஸி, ஆன் / ஆஃப்). |
| Admin “flag” → கொடி / கொடியிடு | **Keep கொடி / கொடியிடு**, but flag a *person* with **மீது**: `{name} மீது கொடியிடு`, `உங்கள் மீது கொடியிட்டவர்கள்`, matching the existing `உங்கள் மீதான கொடிகள்` (7 entries changed). கொடியிடு is the established Google Tamil calque for “flag” (mail, Maps reviews), and it counts naturally (`3 கொடிகள்`, `{total}-இல் {n}-ஆவது கொடி`). **புகார்** is rejected: it means a complaint/report, which over-states what a flag is (a signed vote toward removal, “a decision for the group”) and collides with the “Report” wording users know from other messengers. **குறி** is rejected: it reads as “target/aim” (குறி வை) and is vaguer. A native panel should still confirm (native #2). |
| Buttons: short plain imperatives (“என் கணக்கை உருவாக்கு”) | **Plain imperative is right on buttons.** Android and Google Tamil buttons use it (ரத்துசெய், சேமி, பகிர், நீக்கு, அனுமதி), and with “என்/எனது” it reads as the user's own words, which is what VOICE asks for; it is not rude next to நீங்கள் text, because the button speaks *as* the user, not *to* them. Use polite -உங்கள் only in sentences (titles, leads, errors). First-person verbs (சேமித்துவிட்டேன், ஒப்புக்கொள்கிறேன்) are gender-free and fine. Resolves ta.md's **verify**. |
| Placeholders: “{name} அவர்களுக்கு”-style postpositions | **Accept for person names.** `{name} அவர்கள்` + case is the normal respectful way to inflect a name in written Tamil and never fuses a suffix onto the slot. Prefer a nominative phrasing where it reads naturally (`{name} அழைக்கிறார்`). For non-person slots use an apposition noun (`{group} குழுவை`, `{device} சாதனத்தை`, `{name} கோப்பை`) or **என்பதை** (`{label} என்பதை அகற்று`), never அவர்கள். Hyphen + suffix is fine on number slots (`{total}-இல்`), not on names; never a case suffix as a loose word (`{time} இல்`, fixed). |
| “End-to-end encrypted” = எண்ட்-டு-எண்ட் என்க்ரிப்ட் செய்யப்பட்டது | **Keep.** It is the transliteration WhatsApp Tamil users see. ta.md's suggestion முழுமையாக என்க்ரிப்ட் செய்யப்பட்டது (“fully encrypted”) is rejected: it changes the claim. |
