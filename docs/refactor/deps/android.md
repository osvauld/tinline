## 8. NDK, target API, 16 KB
- Latest NDK: r30 (30.0.16248370) labelled "Latest LTS" (https://developer.android.com/ndk/downloads; page updated 2026-09-08). AGP 9.x default is still r28c (28.2.13676358), which we pin (build.gradle.kts:19, :132 ndkDir). r28+ aligns ELF segments to 16 KB by default. No need to move; optional later to r30 (requires reinstalling NDK, rebuilding libaom with scripts/build_libaom.py for matching toolchain/ABI, cargo-ndk config, and Rust target tests). Not needed for Play.
- Play target API (https://developer.android.com/google/play/requirements/target-sdk): from 2026-08-31 new apps and updates must target API 36 (extension request possible to 2026-11-01); existing apps must target >= 35 to stay visible to new users on newer OS. We already target 36 and the date has passed - we're compliant. API 37 is not required in 2026 by anything I found (likely 2027 by the annual pattern - inference, not confirmed). Behaviour changes for targetSdk 37 will be needed later (Android 17).
- 16 KB: Play requires 16 KB support for apps targeting API 35+ that use native code; updates not supporting it will be blocked from 2027-02-01 (https://developer.android.com/guide/practices/page-sizes). Our status: local arm64-v8a libp2pcore.so at android/app/build/rustJniLibs/arm64-v8a/ has all LOAD segments `align 2**14` (checked with NDK llvm-objdump, read-only) => 16 KB OK with NDK r28c + rustc 1.92. No -z,max-page-size flag is set in the repo (grep: only -Bsymbolic in crates/core/build.rs:6), none is needed with r28 but a regression guard is cheap: add `-C link-arg=-Wl,-z,max-page-size=16384` via cargo-ndk env RUSTFLAGS (not required). JNA's libjnidispatch is 16 KB-clean since 5.16/5.17 (we're on 5.17.0; 5.19.1 fine). AGP >= 8.5.1 packages .so uncompressed+aligned; AGP 9.4 does too. x86_64 builds are emulator-only; Play bundles only include arm64 for real devices (abiFilters x86_64,arm64-v8a).
- Add acceptance check: `zipalign -c -P 16 -v 4 app-release.apk` + `bundletool dump config | grep alignment` (PAGE_ALIGNMENT_16K) + run on 16 KB emulator image (`adb shell getconf PAGE_SIZE` = 16384). Ship-blocking check before 2027-02-01; also confirm libaom static libs are built with r28c (they are linked into libp2pcore.so so inherit the final link alignment).
