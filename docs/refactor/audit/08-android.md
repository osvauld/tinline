# Audit 08 - Android app (android/app/src, read-only)

Paths below: `K/` = `android/app/src/main/kotlin/com/osvauld/p2p/`, `D/` = `crates/desktop/src/`, `C/` = `crates/core/src/`.
Confidence note: I skimmed signatures/heads of all files and read the logic files named; line numbers are from grep and are exact, "lines saved" are estimates.

## 0. Architecture facts (needed to read the rest)
- The core is reached through **UniFFI-generated Kotlin** (`uniffi.p2pcore.*`, generated by gradle task `uniffiBindgen`, build.gradle.kts:148-169), NOT hand-written JNI. The Rust side uses `#[uniffi::export]` in ~16 files (node.rs, chat/api.rs, group/*.rs, voice.rs, video_call.rs, search/api.rs, ...). So "JNI wrapper boilerplate" is essentially absent.
- The ONLY hand-written JNI is `C/video_jni.rs` (110 lines: `Java_com_osvauld_p2p_VideoJni_pushYuv` / `pullRgba`) with `object VideoJni` at `K/VideoIo.kt:219-233`. Two functions, no repetition. docs/video.md:246 documents it.
- Desktop (iced) is a *separate* Rust crate `crates/desktop` (22.5k lines) that depends on `p2pcore` as a normal Rust lib. There is no shared "presentation logic" crate, so every label/format/state-machine exists once in Kotlin and once (sometimes 2-3x) in desktop.

## 1. LOGIC THAT SHOULD MOVE TO SHARED RUST (top priority per user)

### 1.1 Proposed shape: ONE new crate `crates/ui-logic` (name tbd), exported through the existing UniFFI, consumed natively by desktop
UniFFI already gives a generic pattern: plain `pub fn` / `#[derive(uniffi::Record)]` / `#[derive(uniffi::Enum)]` with `#[uniffi::export]`. No per-function JNI is needed; Kotlin calls them as `uniffi.p2pcore.endReasonText(...)`. Rules for the API:
- Pure functions, no clock/zone reads inside: take `now_secs` and a `tz_offset_secs`/zone struct as arguments (Kotlin passes `ZoneId.systemDefault().rules.getOffset(...)`; desktop passes chrono Local). This keeps them deterministic and testable once (one Rust test-suite replaces `BlockingTest`, `HostCondTest`, `AudioRoutesTest`, parts of `GroupsCoreTest`).
- Return **semantic enums + params** where copy differs by locale/voice, plus a default English string from docs/design/VOICE.md copy (single source of copy voice).
- Stateful machines (compose drafts, link UI, onboarding) become `uniffi::Object` with `&self` methods + a callback interface / `poll()` snapshot (the repo already does this with `NodeEvents`, `LinkEvents`, `VideoEvents`, `GroupCallEvents`).
- Do not put in it: Telecom, permissions, notifications, camera/mic, audio devices, Keystore (those are the "thin platform layer" and legitimately stay Kotlin).
