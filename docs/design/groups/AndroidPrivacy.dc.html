Message you is a status, not a switch: a contact can always message, and Block is the only way to stop that. Call you is the one switch. Contacts added by QR start with both on; contacts from a group request start with calls off. Turning calls off takes effect at once on this phone, and on linked devices as they sync. There is no Remove for a contact (Block replaces it); Remove is only for group members. Block tells the contact (signed notice), keeps the chat read-only (chats are never deleted, U24), and refuses them on every device; see the Blocking board. “Connection” reassures that address changes are flowing without exposing any address. Interactive version: refined/privacy.html.

The “Ask Leo to allow calls” message and the exact refusal wording are proposed; the agreed rule is only that calling needs its own permission and starts off for contacts from a group request.

Address changes · Settings › Privacy
Address changes
Your phone gets a new network address on a schedule, whether or not anyone is blocked. Your contacts and group hosts are told automatically. Old addresses stop working; this doesn’t hide you from people you talk to.

Shorter intervals cut off old addresses sooner and may use a little more battery (not measured yet). If you and a contact both change address while apart and share no group, you reconnect with a QR.

One setting: how often. The card shows the last and next change and how many contacts already have the current address, so people trust it is working. The trade-off is stated in one warning line. Linked devices each change their own address; the setting syncs. The interval choices and default are proposed; the real values are an open decision. Contact and group addresses are separate (hosts never learn the contact address; hosts are members’ devices and can read group chats). Blocking never changes either address by itself and never changes group membership. Overdue, failed and waiting states are in the interactive version.
