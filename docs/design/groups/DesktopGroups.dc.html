Three panes: chats, conversation, members. The members pane is a toggle, open by default on wide windows, and shows hosts first with live status. On the host computer the header says so, and the hosts list shows how many members are connected through it. Right-click a member for the same actions as the phone sheet; the same actions must also open from keyboard (Enter on the row, or the menu key) and a visible “…” button, so nothing is right-click only.
