## Original Claude Design boards

Copied from the "Tinline app design" canvas (https://claude.ai/artifact/LGp4JFWCu5qg6eyG6KebpJ),
2026-10-07. Each `*.dc.html` is one board: plain HTML + inline CSS, open it in a browser or read
the markup. `Main.dc.html` holds the tokens (colours, type, spacing, radii, icons); `Flow.dc.html`
the screen flow. The canvas is the source of truth; re-copy when it changes.
