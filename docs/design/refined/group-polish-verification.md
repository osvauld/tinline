Viewports: 1440x1000 (fine pointer), 390x844 and 320x740 (touch), each light and dark. Screenshots: `screenshots/group-polish-*.png`.

Covered:
- Desktop defaults and harness: Weekend hike selected; header is one line "12 members" with no host strip; slim bar with icon-only toggles and the Simulation drawer closed; no Reply/Discard text and no visible message controls when idle. Weekend hike grew from 8 to 12 members so the group-call roster below has a real quiet row and an overflow "+n".
- Group call: the overlay shows a roster, not one avatar — up to k speaking tiles (host tagged, current speaker ringed, muted badged), a quiet row of the rest (6 shown, or 5 at 320px so "+n" never wraps), and a "+n" button that opens the full roster in a sheet. The same roster renders identically from chat.html when a group call started in groups.html is reopened there. Joins and leaves during the call are announced politely. Sound: a quiet `pulse` on joining, `connected` once seated, a soft `pulse` on someone else joining/leaving, `ended` on leaving — never the ring/ringback cues, since a group call rings nobody. A "Quiet mode" switch in the Simulation drawer silences all of it; it defaults on, so headless runs stay silent.
- Bubble system: corner classes and 2 px / 10 px spacing for same-author runs following the `--r-bub` / `--r-bub-tight` table; sender name only on the first bubble of a group (13 px bold, avatar-hue ink); sent mint with no border, received surface with a hairline border, canvas background; meta inline (a single-line bubble stays one line tall; 11 px tabular-nums inside the bubble); event line centred 12 px muted; day separator is a pill.
- Composer: attach 44 px · field at least 44 px · paper-plane Send 44 px at 38% opacity when empty, enabled with a draft.
- Sidebar: request rows are quiet rows with `.t-badge` counts, no banner.
- Desktop menu (light and dark): hover reveals a 24 px chevron beside the bubble without resizing it; it opens an anchored popover (Reply, Copy, Message info; own messages add Edit and Delete); right-click opens the same popover; keyboard Tab reaches the menu button, Enter opens with focus on Reply, Escape returns focus to the message's menu button; Message info explains delivery (not the bubble) and returns focus on close.
- Reply and edit: context strip names Sam with the field focused and no dialog; Escape cancels and keeps focus; sent reply shows the in-bubble quote and a delivered tick; Edit puts the text in the composer with an Editing strip; the edited message shows "edited" in the inline meta.
- Hosts offline: thin warning strip under the header with the title block unchanged; queued message shows the pending clock with no explanatory text in the bubble; Delete removes only that message with an Undo toast and keeps focus; the strip disappears when a host is back.
- Incoming while scrolled up: 36 px scroll-to-latest button with a `.t-badge`, cleared on use.
- Phone (390 and 320, light and dark): opens on the list with a 56 px New group FAB and no row tint; full-height conversation with no visible menu controls; long-press opens a bottom sheet with focus inside; received and own-message actions; Escape returns focus to the message; long-press cancelled by finger movement, scroll and pointercancel, and a short tap does not open it; Enter on touch inserts a newline; transcript scrolls with the composer visible; textarea select-all unaffected; offline strip under the header; new-group sheet at the bottom and within the viewport; no clipping or overflow before or after sends.
- Deep links and embed: `?group=hike` opens the mobile conversation; `mobile.html?screen=groups` contract (conversation, no harness); `?embed=1` has no harness or drawer, zero padding, and fills 100dvh without border or radius; `?embed=1&group=…` is one locked conversation with no back control or list, also at narrow width; `?embed=1` without a group keeps the two-pane app; theme and motion query parameters are honoured; invalid values (`nope`, markup, `hike">`, `../x`) fall back to the list; `?group=<id>&from=home` for hike, family and book opens the conversation and Back goes Home; a removed group opens read-only with no menu buttons and no composer.
- No console errors or failed requests.

Defects found and fixed during the pass-1 run: class name clash with the members list (`.mrow`), release of a long-press closing the sheet via the backdrop click, 320 px header wrapping (Members became an icon button with its name kept for assistive tech; in pass 2 it is icon-only at every width).
