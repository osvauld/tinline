What the mark gives the interface

Felt more than noticed: the rules the product takes from the mark, never a decoration pasted on.

Two ends, mirrored

Sent and received bubbles are exact mirrors: the same radii, padding, maximum width and grouping corners, on opposite sides. The person on each end gets the same shape.

One axis on the call screen

Avatar, name, status and End sit on the centre line, with a matching control either side: Mute · End · Camera. Today there are two buttons and End sits off-centre.

The string goes taut on connect

A tin-can phone only works when the string is tight. Ringing shows it slack, a connected call pulls it straight, once, quietly. Amber means the line itself: "Waiting" is a slack string, not an error. Errors stay red.

Delivered is two marks

Pending is a clock. Delivered is ✓✓: the message is at both ends. This also matches what WhatsApp users already read a double tick as.

Linking is two devices facing

Setup and device linking show the two devices as mirrored ends, one showing the QR code and one scanning it, with the string drawn between them once they've paired.

Balanced edges

Rows that hold actions keep equal 44px ends: back and info in headers, attach and send around the composer, so the content between them sits on the centre line.
