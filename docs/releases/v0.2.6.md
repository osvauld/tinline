# Tinline v0.2.6

Your phone tells you about new messages even while your computer is online, and group hosting is set up in one place.

## Changed

- Groups: hosting is set up in one place, **Hosting permissions** in Group info, with messages and calls side by side.
- Android: the battery row in Settings shows Android's own setting for Tinline (Restricted, Optimized or
  Unrestricted). With wake-ups only Restricted needs a change.
- Android: Settings says your other accounts still ring on this phone when wake-ups are on.
- Text across signup, contacts and groups updated to match how the app works now; the desktop says click, not tap.

## Fixed

- A message to someone whose computer is online now also wakes their sleeping phone, so the phone notifies too.
  (Before, it only reached the phone later through the computer, with no notification.) The sender needs this version.
- Security: the connection slots kept for contacts no longer go to a blocked contact, and a first message from an
  unknown device is limited in size before it is checked.

## Downloads

- **Android, two editions** (arm64-v8a), both signed with the same key. Check them against `SHA256SUMS`.
  - `tinline-play-v0.2.6.apk`: wake-ups through Google. Needs Google Play services; pick this one on most phones.
  - `tinline-liberum-v0.2.6.apk`: no Google code at all; stays connected all the time.
  - **Coming from an earlier version:** install the same edition you have; it updates your app and keeps your data.
- **Linux:** `.deb`, AppImage and tarball, built on Ubuntu 24.04.

## Known limits

- A message reaches a sleeping phone only while the sender's app is still running.
- Desktop and Liberum have no wake-ups. Group calls and posts don't wake a sleeping member yet.
- No iOS release.
- Some text that comes from the shared core (call log lines, a few status cues) is still in English.
