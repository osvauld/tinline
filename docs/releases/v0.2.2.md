# Tinline v0.2.2

The Play edition of v0.2.1 closed straight after opening on some phones. This release fixes that, and Tinline
now speaks nine languages.

## Fixed

- **Play edition crash on start.** When the phone couldn't get its wake-up token from Google, the app closed
  instead of carrying on. Now it carries on without wake-ups, and the release build has the right Google sender
  setting so wake-ups work again.

## New

- **Languages.** Tinline on Android, desktop and iOS is now in English, Finnish, French, German, Hindi, Bengali,
  Malayalam, Marathi and Tamil. On Android, pick one in Settings › Language. The translations are new and still
  being reviewed by native speakers, so tell us when something reads oddly.

## Downloads

- **Android, two editions** (arm64-v8a and x86_64), both signed with the same key. Check them against `SHA256SUMS`.
  - `tinline-play-v0.2.2.apk`: wake-ups through Google. Needs Google Play services; pick this one on most phones.
  - `tinline-liberum-v0.2.2.apk`: no Google code at all; stays connected all the time.
  - **Coming from v0.2.0 or v0.2.1:** install the same edition you have; it updates your app and keeps your data.
- **Linux:** `.deb`, AppImage and tarball, built on Ubuntu 24.04.

## Known limits

- The same as v0.2.1: a message reaches a sleeping phone only while the sender's app is still running; with
  several accounts on one phone only the open one can be woken; desktop and Liberum have no wake-ups; no iOS
  release.
- Some text that comes from the shared core (call log lines, a few status cues) is still in English.
