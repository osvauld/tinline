# Tinline v0.2.5

Calls and first messages that get through to a sleeping phone more reliably.

## Changed

- Calls: a phone woken by a call now dials the caller back, so the call connects even when the caller's own
  connection can't get through.

## Fixed

- A new contact can always wake your phone: right after adding someone, their first message no longer waits until
  you open Tinline. (Your request now waits for its wake-up before it goes, and a missed one is handed over later.)
- A group invitation now reaches a contact whose phone is asleep.
- Android: after you answer a call, a repeat wake-up no longer makes the phone ring again.
- Android: opening a chat on top of another chat starts it fresh; the two contacts' messages no longer mix.

## Downloads

- **Android, two editions** (arm64-v8a), both signed with the same key. Check them against `SHA256SUMS`.
  - `tinline-play-v0.2.5.apk`: wake-ups through Google. Needs Google Play services; pick this one on most phones.
  - `tinline-liberum-v0.2.5.apk`: no Google code at all; stays connected all the time.
  - **Coming from an earlier version:** install the same edition you have; it updates your app and keeps your data.
- **Linux:** `.deb`, AppImage and tarball, built on Ubuntu 24.04.

## Known limits

- A message reaches a sleeping phone only while the sender's app is still running.
- Desktop and Liberum have no wake-ups. Group calls and posts don't wake a sleeping member yet.
- No iOS release.
- Some text that comes from the shared core (call log lines, a few status cues) is still in English.
