# Tinline v0.2.3

A maintenance release. The apps work the same as v0.2.2; this one changes only how releases are built.

## Changed

- Release builds reuse cached dependencies and skip duplicate test runs, so new versions reach you sooner.

## Downloads

- **Android, two editions** (arm64-v8a and x86_64), both signed with the same key. Check them against `SHA256SUMS`.
  - `tinline-play-v0.2.3.apk`: wake-ups through Google. Needs Google Play services; pick this one on most phones.
  - `tinline-liberum-v0.2.3.apk`: no Google code at all; stays connected all the time.
  - **Coming from an earlier version:** install the same edition you have; it updates your app and keeps your data.
- **Linux:** `.deb`, AppImage and tarball, built on Ubuntu 24.04.

## Known limits

- The same as v0.2.2: a message reaches a sleeping phone only while the sender's app is still running; with
  several accounts on one phone only the open one can be woken; desktop and Liberum have no wake-ups; no iOS
  release.
- Some text that comes from the shared core (call log lines, a few status cues) is still in English.
